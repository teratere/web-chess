# ♟️ Web Chess - 本格Webチェス（vs CPU / 2人対戦）

> **🌐 Live Demo (ロリポップ本番公開版):**  
> ブラウザで今すぐ遊べる公開版はこちら 👉 **[https://selfup.net/chess/](https://selfup.net/chess/)**

キャスリング・アンパッサン・プロモーション（昇格）・ステイルメイトなどの国際公式特殊ルールに完全対応した、ブラウザ完結型の本格Webチェスゲームです。  
外部ライブラリや画像ファイルに依存せず、ベクターSVGによる高精細グラフィックとWeb Audio APIによる効果音合成を内蔵したシングルファイル設計となっています。

---

## 🌟 主な機能 (Features)

### 1. 公式チェスルール完全準拠
- **特殊手対応:**
  - **キャスリング (Castling):** キングサイド（O-O）およびクイーンサイド（O-O-O）。キングとルークの初期位置確認、間マスの通過チェック判定を厳密に実装
  - **アンパッサン (En Passant):** 敵ポーンの2マス前進直後のみ斜め背後から捕獲可能
  - **プロモーション (Promotion):** 最終段到達時にクイーン・ルーク・ビショップ・ナイトから選択
- **厳密な着手判定:** 自殺手・王手放置の完全禁止、チェック・チェックメイト・ステイルメイト（引き分け）の自動判定

### 2. 対局モード & AIアルゴリズム
- **2つの対局モード:**
  - **vs CPU (1人プレイ):** 白番（先手）または黒番（後手）を選択可能
  - **2人対戦 (Pass & Play):** 1台のスマートフォンやPCで交互に指せるローカル対人モード
- **3段階の難易度 (AI):**
  - **初級:** ランダム＋簡易評価による初心者向け
  - **中級:** 駒の基礎価値（PST: Piece-Square Table）を考慮したポジション重視AI
  - **上級:** Minimax探索 ＋ アルファベータ（Alpha-Beta）枝刈りによる先読みAI

### 3. 洗練されたUI & プレイアビリティ
- **レスポンシブデザイン:** PC・タブレット・スマートフォンの全画面で1:1アスペクト比を維持
- **ガイド表示:** 選択マス・合法移動先（ドット／捕獲リング）・直前着手・チェック時の赤色ハイライト
- **サポート機能:** 1手戻す（アンドゥ）、ボード視点反転（白視点／黒視点）
- **リアルタイム棋譜:** SAN形式（代数表記法：e4, Nf3, O-O 等）による手数ログ表示
- **Web Audio打鍵音:** 駒の移動・捕獲・チェック警告をWebブラウザ単体で音響合成
